🟢 2-fős Git napi workflow
Ágak:

main → stabil, mindig futtatható kód

viki → te dolgozol

lilla → társad saját branch-e

Napi rutin lépésről lépésre
1️⃣ Kezdés előtt

Mindig frissítsd a main-t:

git checkout main
git pull

2️⃣ Váltás a saját branch-edre
git checkout viki
git pull origin viki


Most már a saját branch-ed friss és kész a munkára.

3️⃣ Fejlesztés

Dolgozol a kódodon a viki branch-en

Új fájlok, módosítások → csak itt

4️⃣ Commitolás
git add .
git commit -m "Rövid, érthető leírás a változásról"


Érdemes kis, logikus commitokat csinálni, hogy könnyű legyen merge-elni.

5️⃣ Push GitHubra
git push


Most már a GitHubon is friss a viki branch-ed.

6️⃣ Frissítések a main-ből (ha kell)

Ha a társad merge-elt a main-be:

git checkout main
git pull
git checkout viki
git merge main


Ha van konfliktus → Git jelzi, javítod, commitolsz, pusholsz

Ha nincs konfliktus → nyomás, mehet tovább a fejlesztés

7️⃣ Ha kész a feature

GitHubon Pull Request: viki → main

Teszteljétek a kódot → Merge
